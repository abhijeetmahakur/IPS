# Java Practice Exercises

This repository contains separate Java exercise programs named `q*.java`. Each source file is intended to be compiled and run independently.

## Requirements

- A Java Development Kit (JDK) with `javac` and `java` on `PATH`

## Compile and run one exercise

From this repository directory, for example:

```bash
javac q01.java
java q01
```

Replace `q01` with the class name of the exercise being run. Compile one file at a time; generated `.class` files are ignored by `.gitignore`.

## Tests

There is no automated test suite. Compilation and manual execution are the available checks.
