# Java Practice Exercises

This repository contains separate Java exercise programs named `q*.java`. Each source file is intended to be compiled and run independently.

## Requirements

- A Java Development Kit (JDK) 11 or newer with `javac` and `java` on `PATH` (all files compile with JDK 21)

## Run one exercise

From this repository directory, run a source file directly:

```bash
java q01.java
```

To compile first instead, run the class by the name declared in the file. Some files declare `class Q25` (capital `Q`) rather than `q25`:

```bash
javac q25.java
java Q25
```

Generated `.class` files are ignored by `.gitignore`.
